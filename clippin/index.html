ClipPin

복사한 텍스트와 이미지를 모두 기록하고, 자주 쓰는 항목은 고정해 두었다가 숫자 키 한 번으로 붙여넣는 Windows 클립보드 관리자.

텍스트 · 이미지고정 항목내 PC에만 저장Windows x64
다운로드 ClipPin-Setup.msi · 약 50MB · Windows x64 · 관리자 권한 불필요

주요 기능

복사해 둔 것을 다시 찾아 쓰는 일을 빠르고 단순하게 만드는 데 집중했습니다.

텍스트와 이미지 기록

복사하는 즉시 저장합니다. 이미지는 PNG로 보관하고, 같은 내용을 다시 복사하면 중복 없이 맨 위로 올라옵니다.

고정 항목

자주 쓰는 문구나 이미지를 Ctrl+P로 고정하면 목록 맨 위에 모입니다. 자동 정리에서 빠지고, Ctrl+↑↓로 순서를 바꿉니다.

숫자 키로 바로 붙여넣기

고정 항목 1~9번은 팝업을 연 뒤 숫자 하나만 누르면 곧바로 붙여넣어집니다.

선택하면 자동 붙여넣기

항목을 고르면 팝업을 열기 직전에 쓰던 창으로 돌아가 Ctrl+V까지 알아서 보냅니다.

별칭과 그룹

고정 항목에 별칭을 달고 그룹(업무·개인 등)으로 묶어 구분합니다. 검색할 때 별칭도 함께 찾습니다.

바로 검색

팝업을 열자마자 검색창에 입력할 수 있고, 입력하는 대로 목록이 걸러집니다.

내 데이터는 내 PC에만

클립보드에는 비밀번호나 개인 정보가 지나가기 쉬워서, 저장하지 않을 것을 고르는 장치를 넣었습니다.

외부 전송 없음

기록은 이 PC의 %APPDATA%\ClipPin 폴더에만 저장되며 어디로도 보내지 않습니다.

비밀번호 관리자 존중

비밀번호 관리자처럼 "기록하지 마세요"라고 표시한 복사 내용은 저장하지 않습니다.

제외할 앱 지정

설정에서 프로세스 이름(예: KeePass)을 적어 두면 그 앱에서 복사한 내용은 기록하지 않습니다.

일시정지

트레이 메뉴의 "일시정지"를 켜면 다시 끌 때까지 아무것도 기록하지 않습니다.

한눈에 보는 수치

9개숫자 키로 바로 붙여넣는 고정 슬롯 (고정 자체는 개수 제한 없음)
200개고정하지 않은 항목의 기본 보관 개수 · 설정에서 변경 (최소 10)
20MB이미지 한 장의 저장 한도
100만 자텍스트 한 건의 저장 한도

트레이와 설정

ClipPin은 창 없이 작업표시줄 트레이에 상주합니다. 숨겨진 아이콘(^) 안에 있으면 끌어서 꺼내 두세요.

트레이 아이콘동작
왼쪽 클릭팝업 열기 / 닫기
오른쪽 클릭열기 · 일시정지 · 설정 · 종료 메뉴

설정 항목설명
호출 단축키입력칸을 클릭하고 원하는 키 조합을 누르면 바뀜. Ctrl · Alt · Shift · Win 중 하나 이상 포함. 다른 프로그램이 쓰는 조합이면 알려 주고 이전 단축키를 유지

설치와 제거

ClipPin-Setup.msi
keisoft.kr에서 내려받습니다.

다운로드
  1. 내려받은 ClipPin-Setup.msi를 실행합니다. 현재 사용자 전용 설치라 관리자 권한이 필요 없습니다.
  2. 설치 마법사에서 사용 조건에 동의하고 설치 위치를 고릅니다. 기본 위치는 %LOCALAPPDATA%\Programs\ClipPin입니다.
  3. 마지막 화면에서 "ClipPin 지금 실행"을 켜 두면 설치 직후 바로 시작합니다. 이후에는 시작 메뉴에서도 켤 수 있습니다.
  4. 이전 버전이 설치돼 있으면 같은 파일을 실행해 위에 덮어 설치하면 업그레이드됩니다.
설치 파일에 코드 서명이 없어서 Windows가 "알 수 없는 게시자" 경고를 띄울 수 있습니다. 이때는 "추가 정보 → 실행"을 눌러 진행하세요.

제거는 Windows 설정의 "설치된 앱"(제어판의 프로그램 제거)에서 ClipPin을 지우면 됩니다. 시작 시 자동 실행을 켜 두었다면 그 등록도 함께 지워집니다. 기록과 설정이 든 %APPDATA%\ClipPin 폴더는 남겨 두므로, 완전히 지우려면 그 폴더를 직접 삭제하세요.

알아둘 점

  • 기록하는 것은 텍스트와 이미지입니다. 서식은 일반 텍스트로 저장되고, 탐색기에서 복사한 파일 목록은 기록하지 않습니다.
  • 엑셀처럼 텍스트와 이미지가 함께 복사되는 경우에는 텍스트를 저장합니다.
  • 붙여넣기를 하면 팝업이 닫힙니다. 다시 쓰려면 단축키로 열면 됩니다.
  • 관리자 권한으로 실행 중인 창에는 자동 Ctrl+V가 전달되지 않습니다. 이때도 항목은 클립보드에 올라가 있으니 직접 붙여넣으면 됩니다.
  • 다른 프로그램이 같은 단축키를 쓰고 있으면 시작할 때 알려 줍니다. 트레이 아이콘 클릭이나 설정에서 다른 조합을 지정하세요.
  • Windows 11에서 만들고 확인했습니다. Windows 10에서는 아직 확인하지 않았습니다.
