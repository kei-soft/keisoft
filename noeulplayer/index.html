기능

필요한 건 다 있고, 나머지는 없습니다

팟플레이어처럼 익숙한 조작에, 복잡한 설정 화면은 뺐습니다.

대부분의 포맷을 바로 재생

일반판은 LibVLC 엔진에 코덱이 내장되어 있어 MP4, MKV, AVI, WebM, HEVC 등을 추가 설치 없이 재생합니다.

탐색 바 미리보기

탐색 바에 마우스를 올리면 그 위치의 장면이 말풍선 안에서 바로 재생됩니다. 원하는 장면을 한 번에 찾을 수 있습니다. (일반판)

원본 해상도 화면 캡처

Ctrl E 한 번이면 현재 장면이 원본 해상도 PNG로 사진 폴더에 저장됩니다.

재생목록

파일이나 폴더를 끌어다 놓으면 목록에 추가되고, 한 편이 끝나면 다음 파일이 이어서 재생됩니다.

방해 없는 전체 화면

더블클릭으로 전체 화면이 되고, 마우스를 멈추면 컨트롤과 커서가 자동으로 사라집니다.

배속과 키보드 조작

0.2배에서 4배까지 속도를 조절하고, 탐색·볼륨·캡처까지 거의 모든 동작을 키보드로 할 수 있습니다.

설치

세 단계면 끝납니다

  1. 설치 파일 실행

    내려받은 NoeulPlayer-1.1.0-x64.msi(Lite판은 NoeulPlayer-Lite-1.1.0-x64.msi)를 실행합니다. 아직 코드 서명이 없어 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누르세요.

  2. 관리자 권한 허용

    모든 사용자용으로 C:\Program Files\NoeulPlayer에 설치되며, 시작 메뉴와 바탕 화면에 바로가기가 생깁니다.

  3. 기본 플레이어로 지정 (선택)

    동영상 파일을 우클릭해 연결 프로그램 → 다른 앱 선택 → NoeulPlayer → 항상을 누르면 더블클릭으로 바로 열립니다.
