WorkLog 는 날짜별 일지에 표·그림·할 일·SQL 쿼리를 함께 적고, 결과까지 그 자리에서 확인하는 Windows 업무일지 프로그램입니다.

하루의 기록에 필요한 것을 한곳에

메모장과 엑셀, DB 도구를 오가지 않아도 됩니다. 일지 안에서 쓰고, 정리하고, 실행하고, 다시 찾습니다.

📅

날짜별 일지 + 정보 노트

업무 탭은 월별로 묶인 일지, 정보 탭은 날짜와 상관없는 메모(서버 주소, 자주 쓰는 쿼리). 그룹으로 묶고 맨 위에 고정할 수 있습니다.

🗂️

열린 일지는 탭으로

일지를 열면 브라우저처럼 위에 탭이 생기고, 닫아도 다음 실행 때 열어 둔 탭이 그대로 돌아옵니다.

✅

할 일 ↔ 본문 카드

할 일을 입력하면 목록과 본문에 색깔 카드가 함께 생기고, 체크하면 양쪽이 같이 바뀝니다. 완료한 항목만 빼고 다음 일지로 이월합니다.

▦

표 · 그림 · 슬래시 명령

세로선을 끌어 열 너비를 조절하고, 캡처 이미지는 Ctrl+V 로 붙여넣습니다. / 로 제목, 번호 목록, 콜아웃, 구분선 등을 넣습니다.

🔗

링크 · 태그 · 백링크 · 검색

[[ 로 다른 일지에 링크하고 #태그 로 분류합니다. 제목+본문 전체 검색, 현재 노트 안 찾기, 모든 기능을 이름으로 부르는 명령 팔레트가 있습니다.

🗃️

SQL · JSON 정리

붙여넣은 긴 쿼리를 Ctrl+Q 로 보기 좋게 정리하고, JSON 은 Ctrl+J. 서브쿼리·CASE·WITH 까지 정리합니다.

⚡

그 자리에서 쿼리 실행 (PostgreSQL / Oracle)

쿼리 위에 커서를 두고 Ctrl+Enter. 일지마다 쓸 DB 연결을 기억해서 일지를 열면 자동으로 그 DB 로 연결됩니다.

  • 실행 중 취소 버튼, 조회가 아닌 쿼리는 실행 전 확인
  • 결과 표: 접기·높이 조절, 전체 복사(엑셀), CSV 저장, 본문에 표로 삽입
  • 결과 행 우클릭 → UPDATE 쿼리 자동 작성 (기본키를 DB 에서 찾아 WHERE 로 사용)
🐙

Git PR 가져오기

그날 내가 만든 PR 을 저장소별로 정리해 본문에 넣고, 열린 PR 은 할 일로 추가해 다음 일지로 이어 줍니다. (GitHub CLI 필요)

📄

md / txt 뷰어

마크다운을 제목·표·코드·그림까지 뷰어처럼 보여 주고, 파일을 창에 끌어다 놓아도 열립니다.

🚀

프로그램 · 폴더 바로가기

사이드바 맨 아래에 자주 쓰는 프로그램(클릭하면 관리자 권한으로 실행)과 폴더(탐색기로 열기)를 아이콘 버튼으로 둡니다. 사이드바는 좁은 띠로 접을 수 있습니다.

이렇게 시작하세요

처음 실행하면 따라 하기 좋은 예시 일지가 맨 위에 고정되어 열립니다. 아래 순서만 해 보면 대부분의 기능을 만나게 됩니다.

  1. 일지 만들기왼쪽 + 새 업무일지 로 오늘 일지를 만들고 제목과 날짜를 정합니다. 3초 뒤 자동 저장됩니다.
  2. 할 일 적기상단 입력칸에 할 일을 쓰고 Enter. 본문에도 카드가 생기니 카드 아래에 자세한 내용을 이어서 적습니다.
  3. 표·그림 넣기/ 를 눌러 표를 넣거나, 캡처한 화면을 Ctrl+V. 그림 모서리를 끌어 크기를 바꿉니다.
  4. 쿼리 실행하기툴바 연결 관리 에서 DB 를 등록하고, 쿼리를 붙여넣어 Ctrl+Q 로 정리한 뒤 Ctrl+Enter.
  5. 내일로 이어가기일지를 우클릭 → 다음 업무일지 만들기. 완료한 할 일은 빠지고 남은 일만 넘어갑니다.

내 데이터는 내 PC 에만

일지와 DB 연결 정보는 외부로 전송되지 않습니다. 노트가 쌓여도 느려지지 않도록 저장 방식을 설계했습니다.

💾

바뀐 노트만 저장

SQLite 파일 하나(%AppData%\WorkLog\data.db)에 노트를 한 건씩 저장합니다. 편집한 노트만 다시 쓰고, 본문은 열 때만 읽어서 노트와 그림이 많아져도 저장·시작이 빠릅니다.

🛟

실수해도 되돌립니다

  • 삭제한 노트는 휴지통에 30일 보관
  • 하루 한 번 자동 백업(최근 7개) → 백업에서 복원
  • 파일이 깨지면 시작할 때 최근 백업으로 자동 복구
🔐

연결 정보는 암호화

DB 연결 문자열(비밀번호 포함)은 Windows 사용자 계정으로 암호화되어 저장됩니다. 다른 PC 나 계정으로 파일을 옮기면 연결 정보만 다시 입력하면 됩니다.

🧷

두 번 실행되지 않아요

같은 데이터로는 한 번에 하나만 실행되어, 두 창이 서로의 내용을 덮어쓰는 일이 없습니다. 다시 실행하면 열려 있는 창이 앞으로 옵니다.

설치

WorkLog-Setup.msi 를 실행하면 설치 마법사가 안내합니다. 관리자 권한이 필요 없고 .NET 을 따로 설치하지 않아도 됩니다.

설치 · 업데이트

  • 사용자 폴더(%LocalAppData%\Programs\WorkLog)에 설치
  • 시작 메뉴에 “WorkLog” 바로가기 생성
  • 새 버전 MSI 를 위에 설치하면 자동으로 교체

삭제

설정 > 앱 > 설치된 앱에서 삭제합니다. 일지 데이터(%AppData%\WorkLog)는 남으므로 다시 설치해도 이어서 쓸 수 있습니다.

이전 버전에서 올 때

예전 data.json 은 처음 실행할 때 자동으로 새 저장소로 옮겨지고, 원본은 data.json.migrated-날짜 로 그대로 보관됩니다.

사용 방법 문서는 프로그램 안에서 Ctrl+P → “사용 방법” (또는 툴바의 ❔ 사용법)으로 언제든 볼 수 있습니다.
