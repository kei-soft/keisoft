ZipRush

모든 CPU 코어를 한꺼번에 써서 빠르게 압축하고 푸는 Windows 압축 프로그램. 탐색기 우클릭만으로 끝납니다.

zip · tar.zst멀티스레드AES-256 암호Windows 10 / 11
다운로드 ZipRush-Setup.msi · Windows 10 / 11 · 관리자 권한 불필요

주요 기능

자주 쓰는 압축 작업을 빠르고 단순하게 처리하는 데 집중했습니다.

병렬 압축

zip은 파일마다, tar.zst는 4MB 블록마다 나눠 여러 코어가 동시에 압축합니다.

우클릭으로 바로

파일·폴더를 우클릭해 zip으로 압축하고, 압축 파일은 우클릭으로 바로 풉니다.

내용 미리 보기

압축을 풀지 않고 폴더 트리와 파일 목록을 보고, 이름으로 검색하고, 파일을 더블클릭해 열 수 있습니다.

일부만 풀기

목록에서 원하는 파일이나 폴더만 골라 풉니다.

암호 zip

압축 설정에서 암호를 입력하면 AES-256으로 암호화한 zip이 만들어집니다.

끌어다 놓기

창에 파일을 끌어다 놓으면 압축하고, 압축 파일을 놓으면 내용을 엽니다.

속도 예시

node_modules가 들어 있는 ECharts 프로젝트 폴더로 이 PC에서 직접 측정한 값입니다. PC 사양과 디스크에 따라 달라집니다.

탐색기 우클릭 메뉴

설치할 때 "탐색기 우클릭 메뉴" 기능을 켜 두면 등록됩니다. Windows 11에서는 "추가 옵션 표시"를 눌러야 보일 수 있습니다.

설치와 제거

ZipRush-Setup.msi
keisoft.kr에서 내려받습니다.

다운로드
  1. 내려받은 ZipRush-Setup.msi를 실행합니다. 현재 사용자 전용 설치라 관리자 권한이 필요 없습니다.
  2. 기능 선택 화면에서 "탐색기 우클릭 메뉴"와 "zip / zst 파일을 ZipRush로 열기"를 켜거나 끕니다.
  3. 마지막 화면의 체크박스를 켜 두면 Windows 설정 화면이 열립니다. 거기서 .zip을 ZipRush로 선택하세요.
Windows 10/11은 보안상 프로그램이 스스로 기본 앱이 되는 것을 막습니다. 그래서 설정 화면에서 한 번만 직접 골라야 합니다. ZipRush 창 위의 안내 줄에서도 같은 화면을 열 수 있습니다.

제거는 Windows 설정의 "설치된 앱"(제어판의 프로그램 제거)에서 ZipRush를 지우면 됩니다. 우클릭 메뉴와 연결 정보도 함께 사라집니다.

알아둘 점

  • 암호가 걸린 zip은 병렬이 아니라서 더 느리고, 빈 폴더는 담기지 않습니다.
  • 압축 파일 안의 실행 파일(.exe 등)을 더블클릭해 열 때는 먼저 확인을 묻습니다.
  • 압축 파일 안의 경로가 풀 위치 밖을 가리키면 풀기를 거부합니다.
  • GPU는 사용하지 않습니다. 압축 알고리즘의 특성상 일반 파일 압축에서는 CPU 병렬 처리가 더 효율적입니다.
