주요 기능

자막을 뽑는 일이 클릭 몇 번으로 끝나는 데 집중했습니다.

끌어다 놓기

mp4 · mov · avi · mkv · webm · m4v · ts · flv 영상을 창에 놓으면 바로 선택됩니다. 저장 위치는 기본으로 영상이 있는 폴더입니다.

필요한 것은 알아서 설치

FFmpeg가 없으면 처음 실행할 때 자동으로 내려받고, Whisper 모델도 처음 쓸 때 한 번만 받습니다. 직접 설치할 것이 없습니다.

GPU 가속

Vulkan을 지원하는 GPU(NVIDIA · AMD · Intel)를 자동으로 찾아 가속하고, 안 되면 CPU로 넘어갑니다. 어느 모드인지는 실행 전에 화면에 미리 보여 줍니다.

모델 선택

tiny · base · small · medium · large 중에서 고릅니다. 기본은 정확도가 가장 높은 large입니다.

7개 언어 설정

한국어 · 영어 · 일본어 · 중국어 · 스페인어 · 프랑스어를 지정하거나, auto로 언어를 자동 감지합니다.

내 PC에서 처리

음성 인식은 이 PC 안에서만 이루어집니다. 영상이나 자막을 외부로 보내지 않습니다.

결과물 (SRT)

영상과 같은 이름으로 저장되는 표준 SRT 파일입니다. 대부분의 동영상 플레이어와 편집 프로그램에서 바로 열립니다.

파일은 UTF-8(BOM 포함)로 저장돼 메모장에서도 한글이 깨지지 않습니다.

모델 고르기

모델이 클수록 정확하지만 더 느리고 용량이 큽니다. 처음 쓰는 모델은 한 번만 내려받고, 이후에는 저장된 것을 재사용합니다.

모델내려받는 크기특징
tiny약 75MB가장 빠름. 정확도는 낮아 시간이 어긋나거나 오인식이 잦을 수 있음

small약 470MB속도와 정확도의 균형

large약 3GB정확도 최고 (large-v3). 기본값. 시간 어긋남도 가장 적음

받아서 실행하기

AutoSub-portable.zip
압축을 풀고 AutoSub.exe를 실행하면 됩니다.

다운로드
  1. zip 파일을 쓰기가 가능한 폴더(바탕화면, 문서, 다른 드라이브 등)에 풉니다. C:\Program Files 아래는 피하세요.
  2. AutoSub.exe를 실행합니다. 처음에는 FFmpeg를 자동으로 내려받느라 잠시 걸립니다(약 80MB).
  3. 영상을 끌어다 놓고 모델과 언어를 고른 뒤 자막 추출 시작을 누릅니다. 모델은 처음 쓸 때 한 번 내려받습니다.
  4. 끝나면 영상 옆(또는 지정한 폴더)에 .srt 파일이 생깁니다. "저장 폴더 열기" 버튼으로 바로 열 수 있습니다.
코드 서명이 없어서 Windows가 "알 수 없는 게시자" 경고를 띄울 수 있습니다. 이때는 "추가 정보 → 실행"을 누르면 됩니다.

삭제는 폴더를 통째로 지우면 끝입니다. 레지스트리나 시작 메뉴에 남는 것이 없습니다. 내려받은 FFmpeg(tools)와 모델(models)도 같은 폴더 안에 있습니다.

알아둘 점

  • 처음 실행할 때와 새 모델을 처음 쓸 때는 인터넷 연결이 필요합니다. 한 번 받은 뒤에는 오프라인에서도 동작합니다.
  • 자막 시간은 AI가 추정한 값이라 말이 시작되는 순간과 0.2~0.5초 정도 어긋날 수 있습니다. 큰 모델일수록 정확합니다.
  • 긴 무음이나 배경음악이 많은 영상은 구간이 어긋나거나 문장이 반복될 수 있어, 이를 줄이는 설정을 넣어 두었습니다.
  • GPU 모드가 "CPU"로 나오면 인식이 훨씬 오래 걸립니다. 이때는 작은 모델을 쓰는 것이 낫습니다.
  • 배경음이 큰 영상이나 여러 사람이 동시에 말하는 장면은 인식 정확도가 떨어질 수 있습니다.
  • Windows 11에서 만들고 확인했습니다. Windows 10에서는 아직 확인하지 않았습니다.
