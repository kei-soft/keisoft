QuickCapture

항상 화면 위에 떠 있다가, 필요한 순간 바로 찍는 가벼운 Windows 캡처 도구입니다.

⬇ 설치 파일 다운로드 QuickCapture.msi · 65.5 MB · Windows 10/11

왜 빠른가요

프로그램이 메모리에 상주하기 때문에, 누르는 즉시 화면을 찍습니다. 앱을 새로 띄우는 대기 시간이 없습니다.

한 번의 동작으로 선택

드래그하면 영역, 클릭하면 마우스 아래 창이 캡처됩니다. 모드를 따로 고를 필요가 없습니다.

메뉴·툴팁도 캡처

선택 화면을 띄우기 전에 먼저 화면을 찍어서, 클릭하면 사라지는 메뉴와 툴팁도 그대로 담깁니다.

바로 편집

사각형, 선, 모자이크, 블러를 넣고 색과 굵기를 정합니다. 도형은 옮기거나 지울 수 있고 되돌리기도 됩니다.

바로 저장·복사

캡처하면 클립보드에 자동 복사됩니다. 이름을 넣고 Enter 한 번이면 PNG로 저장됩니다.

어디서든 시작

떠 있는 아이콘, 트레이 아이콘, 전역 단축키 중 편한 방법으로 시작합니다.

다크 디자인

화면 배율이 달라도 선명하게 보이도록 모니터별 DPI를 지원합니다.

사용법

  1. 캡처 시작 — 떠 있는 아이콘을 클릭하거나 PrtSc 를 누릅니다.
  2. 대상 선택 — 영역을 드래그하거나 창을 클릭합니다. 취소는 Esc 입니다.
  3. 편집 — 필요하면 도형이나 모자이크를 넣습니다.
  4. 저장 — Ctrl+S 로 이름을 정하고 Enter 를 누릅니다. Ctrl+O 로 저장 폴더가 열립니다.

단축키

키동작
PrtSc / Ctrl+Shift+X캡처 시작 (어떤 창이 앞에 있어도 동작)
Esc캡처 취소 / 편집창 닫기
Ctrl+S이름 입력 후 PNG 저장
Ctrl+C편집한 이미지를 클립보드에 복사
Ctrl+O저장 폴더 열기 (저장한 파일이 선택된 상태)
Ctrl+Z되돌리기 (그리기·이동·삭제)
Delete선택한 도형 삭제
Shift + 선 드래그가로/세로 직선으로 고정

설치

QuickCapture.msi 를 내려받아 실행하면 됩니다. (GitHub 페이지에서 보기)

관리자 권한 불필요

현재 사용자 전용으로 설치되고, 시작 메뉴에 바로가기가 만들어집니다.

.NET 포함

런타임이 함께 들어 있어 별도로 설치할 것이 없습니다.

자동 실행

아이콘 우클릭 메뉴의 "Windows 시작 시 자동 실행"을 체크하면 부팅할 때 함께 시작합니다.

서명되지 않은 설치 파일이라 처음 실행할 때 Windows SmartScreen 경고가 나올 수 있습니다. 제거는 설정 > 앱에서 할 수 있습니다.
